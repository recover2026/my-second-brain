## 一、要"真国风"，不是换肤

用户标准：**必须有国风氛围底图 + 纹样装饰**（祥云 / 回纹 / 水墨远山 / 青绿山水 / 鎏金边框 / 印章 / 题跋）。

❌ 反面：交付三套"同一矢量骨架换配色"的简约模板，被回怼 ——
> "也没有国风的啊　你这不都是简约的么　整好看一些的模版"

✅ 正确四步：
1. 图像生成产出真国风底图（封面 + 内页各一张）；
2. PIL 去右下角水印并裁成 16:9 满版；
3. python-pptx 叠加鎏金边框 / 章节圆章 / 引文框 / 印章 / 题跋带；
4. **交付前必做渲染级目检**。

## 二、"爱码字"的毛病要改（第二次回怼）

> 用户原话："你爱码字的毛病没改，要用一些新的结构"

具体要求：
1. **每页只讲一件事**，正文压到 **≤4 条短句（每条 8–12 字）**，不要堆 3–4 大段正文＋引文＋出处＋备注；
2. **多页不能共用同一套骨架** —— 须用多种版式轮换：
   金句大字页 / 三栏卡片 / 左文右图·右文左图镜像 / 章节隔页 / 时间轴 / 结语页。

## 三、已知坑

- AI 生成底图右下角带"AI生成 WORKBUDDY"水印 → 必须裁掉或同区补图；
- 底图自带金色竖线会**穿透**半透明面板 → 面板 alpha 需 **≥ 0.72**。
