## 定位

01–14 号库提供**资料**，但没有回答：**拿到一堆数据，怎么想？**
本篇是经营分析的思维模型。

## 一、分析的三层递进

```
第 1 层  发生了什么  →  数据口径统一（同比/环比/达成率/占比）
第 2 层  为什么会这样 →  拆因子（规模 vs 价格 vs 结构 vs 灾害）
第 3 层  该怎么办    →  提质打法（存量整改 + 增量拓展）
```

> 绝大多数汇报死在第 1 层就结束 —— **只有数据没有归因，等于没分析**。

## 二、农险经营四问（每次分析必答）

1. **量**：保费规模达成？份额变化？（注意：全省合计 ≠ 单家机构）
2. **质**：COR 构成拆解 —— 赔付率、费用率各自贡献了多少？
3. **结构**：险种结构 / 机构结构 / 政策性与商业性占比，是否在退化？
4. **灾**：本期灾害是否异常？赔付是否有灾害口径外的恶化？

## 三、归因漏斗（由粗到细）

总量变动
→ 拆 **规模效应**（承保面积 / 头数 / 保额）
→ 拆 **价格效应**（费率调整 / 条款变更）
→ 拆 **结构效应**（险种 / 区域 / 渠道迁移）
→ 拆 **损失效应**（灾害年景 vs 管理质量）
→ 定位到**具体机构 / 具体险种 / 具体县区**

## 四、结论的四维闭环

任何分析结论必须配套：
**核心优势 + 现存风险 + 落地步骤 + 优化建议**。缺一维即不闭环。

## 五、红线

- 未经系统导出的数字**不得入正式材料**；
- 推算值必须标注「模拟测算」；
- 引用权属必须精确，禁止把区域合计记到单家机构头上。
